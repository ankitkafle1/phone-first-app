# Phone First App Frontend

Expo React Native app for iOS and Android, with limited web access.

## Product Stance

This is a phone app first. The web version exists as a convenience path and may be read-only, limited, or less polished when needed. Mobile functionality should not be weakened for web compatibility.

## Commands

```sh
npm install
npm run start
npm run ios
npm run android
npm run web
npm run typecheck
```

## Stack

- React Native
- Expo SDK 54
- Expo Router
- TypeScript
